# Getting help

Everyday Runtime is maintained in the open, on a best-effort basis. There is no
paid support and there are no private support channels.

| You want to… | Go to |
| --- | --- |
| Report a bug | [New issue → Bug report](https://github.com/micha16372/everyday-runtime/issues/new?template=bug_report.yml) |
| Tell us a suggestion was wrong | [New issue → Suggestion felt wrong](https://github.com/micha16372/everyday-runtime/issues/new?template=suggestion_feedback.yml) |
| Propose a feature | [New issue → Feature request](https://github.com/micha16372/everyday-runtime/issues/new?template=feature_request.yml) |
| Ask a question or share how you use it | [GitHub Discussions](https://github.com/micha16372/everyday-runtime/discussions) |
| Report a security problem | **Only** as described in [SECURITY.md](SECURITY.md) — never in a public issue |
| Get Twenty itself running | [Twenty documentation](https://docs.twenty.com) and the Twenty community |

Before opening an issue, please check [SETUP.md](SETUP.md) (troubleshooting) and
search existing issues. Please leave personal household details out of public
issues.
