# Maintainers

| Role | GitHub |
| --- | --- |
| Primary maintainer | [@micha16372](https://github.com/micha16372) |

The primary maintainer reviews and merges pull requests, triages issues, cuts
releases and handles security reports.

## How decisions are made

- Behaviour of the inference engine follows
  [docs/PRODUCT_PRINCIPLES.md](docs/PRODUCT_PRINCIPLES.md); changes to those
  principles are discussed in an issue first.
- Every change to `main` goes through a pull request with green CI.
- Releases follow [Semantic Versioning](https://semver.org/) and are described in
  [CHANGELOG.md](CHANGELOG.md).

## AI assistance

Parts of this project are written and reviewed with AI coding assistants. Such
commits carry a `Co-Authored-By` trailer. A human maintainer decides what is merged
and released.

## Becoming a maintainer

Regular, high-quality contributions and reviews are the path to commit access.
There are no other maintainers yet — this file will be updated when that changes.
